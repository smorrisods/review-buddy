# Design prototype (reference only)

These files are the original design prototype for review buddy: a design board with every layout and screen side by side (`Review Buddy Board.dc.html`), a single clickable prototype (`ReviewBuddy.dc.html`) and the Liminal HQ design-system assets it uses (`_ds/`, `support.js`).

They are kept **for reference only**. They aren't built, tested or maintained, and the shipped app is the source of truth: where the prototype and the app disagree, follow `docs/SPEC.md` and the other files in `docs/`. Don't edit these files to track the app.
