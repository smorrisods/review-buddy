Review Buddy
A ratatui dashboard that pulls every GitHub pull request and GitLab merge request into one calm queue, so you can read the diff, approve, comment and merge without leaving the terminal. Release Buddy's sibling.
Assumptions. 160×40 terminal, truecolour. Rounded borders (ratatui BorderType::Rounded). Tokens via gh / glab or personal tokens, stored in the OS keyring.
Calm by default. Buckets, not unread counts: Waiting on you, Worth a look, Can wait. Bots go to Noise. Every list ends with "That's everything."
Every frame is live. Click one, then use the keys: ↑↓, ⏎ diff, a / x / c / s / m, v, 1–5, / search, ⌃K commands, T theme, L layout, J Jax.
1Dashboard layouts
1aThree panes sources · queue · overview. Easiest to scan, aggregate or filter by source.
1bList + diff dense one-line rows, the diff is always visible. Sources move to the top tabs.
1cOne at a time step through a bucket, approve and move on. Closest to a calm inbox.
