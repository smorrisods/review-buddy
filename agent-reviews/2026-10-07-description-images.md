# 2026-10-07: images from the change description in the Overview

**Worked:** `ratatui-image`'s `SlicedImage` clips a picture row by row on every protocol (sixel, kitty, iTerm2, halfblocks), so there is no "partially visible, show a placeholder instead" path to maintain. Reserving blank rows in the description's `Vec<Line>` and drawing pictures over them after the text kept scrolling, `max_scroll` and the hit maps untouched. Halfblocks are plain text in a `TestBackend`, which made the frames snapshot-able without ever recording real sixel bytes. Splitting the description into text and image segments with `pulldown-cmark`'s offset iterator handled reference-style images and links around images with no regular expressions.

**Friction:** the library's `Picker::from_query_stdio` times out cleanly, but the thread it spawns stays blocked reading stdin, so on a terminal that never answers it would swallow the first key. On Unix the query is now our own: the library's query string and parser, but a `poll` with a deadline, so nothing is left behind. Windows still uses the library's query. A test that waits twice for a 20 second limit in an `||` made one pty test take 40 seconds; the sixel check is now a single wait on the device control string. The first version of the unit tests asked for images from the `Tick` after loading, when the request had already gone out with the `Loaded` message; the helpers now return the commands a load produces. `url` was an optional demo-only dependency and became a plain one.

**Decisions worth knowing:** the token goes only to a source's web and API hosts and only over https. Content hosts (`*.githubusercontent.com`) count as the forge's for `forge-only` but get no token, because their addresses are signed and some refuse a bearer token on top. Redirects are followed by hand so the rules apply at every hop. The placeholder is `▣ image: alt` rather than an emoji, because a wide glyph that `unicode-width` counts as one cell would misalign the line. Images in the Conversation tab are not drawn: that tab lists threads, not comment bodies, so only the Overview's latest comment gets a one-line note.

**Not verified:** real sixel, kitty and iTerm2 output on a real terminal, and Windows Terminal in particular. The pty test answers the query by hand and checks that a device control string is sent.
