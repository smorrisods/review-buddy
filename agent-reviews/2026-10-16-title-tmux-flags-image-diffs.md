# 2026-10-16: window title, tmux colour, flags and image diffs

**Worked:** the Overview's image pipeline (`ratatui-image`, the URL-keyed `State`, the fetcher with its host and token rules) carried the diff feature almost unchanged: the new code is address building, a layout module and a renderer, and the fetches go through the same limits, cache and `ui.images` setting as description images. Keeping the layout geometry (`images::diff::panels`, `fit_in`) pure made each of the four layouts testable without drawing anything. Halfblocks again made the frames assertable as plain text. The tmux fix is one question to tmux (`client_termfeatures`) rather than a guess from environment variables, with the parsing separated from the process call.

**Friction:** the WSL2 disk filled during a full test run and killed the session; the work was all on disk and in git, so resuming meant re-running the suite. `cargo test --workspace` stops at the first failing binary, so a fixture test failing early hid every later suite: use `--no-fail-fast` for the full picture. The new demo image file raised the demo change's file count, which moved eight image snapshots and tripped a fixture test that assumed every file has counted lines. A wall-clock test (`a_long_conversation_draws_quickly`) fails when the machine is loaded by something else; it passes alone on a quiet machine.

**Decisions worth knowing:** image diffs build forge API addresses from the source's host, so a separate `api_url` isn't used yet, and the base commit is the one the forge reports, which is not always the merge base. GitHub's contents API only returns file bytes for its raw media type, so the fetcher now sends `application/vnd.github.raw+json` ahead of `image/*`. Flags are a small JSON file written on each toggle rather than the debounced draft machinery. The window title strips control characters from forge text.

**Not verified:** a real tmux session, a real terminal's tab bar, and real sixel, kitty or iTerm2 output for image diffs. Nothing was run against live GitHub or GitLab; the raw media type and GitLab's raw file endpoint are from their documentation.
